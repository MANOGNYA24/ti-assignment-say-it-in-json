  3. What the verifier proves — and the trap

  that json_eval.py exists:

  - Independent (this is what gets cross-checked): walker.py+interpolate.py's

    not import walker/interpolate. A passing verifier is real evidence these two
    independently-written algorithms agree.

    pfcfg/parser.py (file grammar — sections, includes, conditionals,

    segments identically, before either walk/resolve algorithm runs. The
    verifier cannot see that: both "independent" evaluators would agree,
    wrongly, on the same misread input.

  walk+interpolation algorithm was ported correctly; it does not prove the 
  file/value grammar was read correctly, since both sides consume that grammar
